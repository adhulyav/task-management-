
# TASK MANAGEMENT SYSTEM
# ===============================================

# 1. Project Description
# ------------------------

- The Task Management System is a Python-based application that helps users organize and manage their daily tasks efficiently. It allows users to add, view, update, edit, and delete tasks. The system uses an SQLite database to store task information and track task progress.

# 2. Features
# ---------------
User Features

- User Registration and Login
- Add New Tasks
- View Tasks
- Update Task Status
- Edit Existing Tasks
- Delete Tasks
- Set Task Priority to Low, Medium, or High
- Track Task Status as Pending, In Progress, or Completed
- Logout

Admin Features

- Admin Login
- View Admin Dashboard
- View Total, Completed, Pending, and In-Progress Tasks
- View User Progress
- View All Tasks with Task ID, Title, Deadline, Priority, and Status
- Logout

# 3. Technologies Used
# --------------------
- Python
- SQLite
- Visual Studio Code

# 4. Requirements
# ------------------

Software Requirements

- Python 3
- Visual Studio Code or another code editor
- SQLite database support

Hardware Requirements

- Computer or Laptop
- Minimum 4 GB RAM
- Keyboard and Mouse

# 5. Project Files
# --------------------
- "main.py" - Starts the application and displays the main menu.
- "admin.py" - Handles admin-related features.
- "task.py" - Handles task management operations.
- "user_auth.py" - Handles user registration and login.
- "task_management.db" - SQLite database used to store project data.

# 6. Database Schema
# ------------------------
The project uses an SQLite database named "task_management.db" to store task information. Each task includes a Task ID, title, deadline, priority, and status.

Task Priority: Low, Medium, High

Task Status: Pending, In Progress, Completed

# 7. How to Run the Project
# --------------------------------
1. Download or clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Ensure Python is installed on your computer.
4. Open the terminal in Visual Studio Code.
5. Run the following command:

python main.py

6. Follow the on-screen menu to register, log in, or access the admin menu.
7. Use the available options to manage tasks and track progress.
